# G1C PHASE-1 GRADER PACK — слепая оценка «Личного мифа»

> **Назначение:** независимая слепая (Phase-1) оценка синтетических Мифов по рубрике шкал 1–6 и задачам A/B/C.
> В этот пакет **не включены**: скрытый контекст кейсов, исходные ответы-источники, ground-truth-метки (какой кандидат истинный, ожидаемые ответы задач), результаты других оценок, ревью-образцы и какие-либо вердикты. Все кейсы обезличены; идентификаторы `G1C-S-##` — синтетические метки, не персональные данные.
> Финальный вердикт по пакету выносится только после агрегации оценок независимых грейдеров; данный пакет никаких выводов не содержит.

---

## 1. Входные файлы (этот каталог)

| Файл | Содержимое |
|---|---|
| `G1C_PHASE1_MYTHS.jsonl` | Мифы (вывод генерации (полный текст Мифа)) по кейсам: `case_id`, `run_id`, `output` (где Миф присутствует) |
| `G1C_PHASE1_IDENTITY_MATCHING.json` | Задача A (5-way идентификация источника) + задача C (genericness) |
| `G1C_PHASE1_COUNTERFACTUALS.json` | Задача B (контрфактическая подмена) |
| `G1C_PHASE1_SCHEMA.json` | Схема выходного JSON (Phase-1) |

Оцениваются только кейсы, у которых в `G1C_PHASE1_MYTHS.jsonl` присутствует `output.story_result`. Кейсы без `story_result` в Phase-1 пропускаются.

---

## 2. Жёсткие правила грейдера

1. **Оценка по тексту, не по намерению.** Красивый текст, не опирающийся на доступные материалы (ответы-кандидаты), — низкий `grounding` независимо от литературного качества.
2. **Цитата обязательна.** Каждая оценка ≥7 и ≤3 должна иметь цитату из Мифа или из ответов-кандидатов (референс: `q1`–`q4`, `story`, `mirror.*`, `meaning[]`, `one_step`, `journal_question`, `title`, `disclaimer`).
3. **Запрещено** исправлять Миф, дописывать, «рекомендовать», вести диалог с персонами. Это оценка, а не рерайт.
4. **Формат ответа:** строго JSON по `G1C_PHASE1_SCHEMA.json` (по одному объекту на Миф). Допустимы только значения из enum'ов схемы.
5. **Не использовать внешние знания** о кейсах, источниках и процессе генерации: судить только по материалам этого каталога.

## 3. Рубрика — шесть шкал (0–10), Phase-1

| # | Шкала | 0–3 | 4–6 | 7–10 |
|---|---|---|---|---|
| 1 | **grounding** — опора на ответы-кандидаты | текст почти не связан с ответами; образы подменены | частичная опора; часть образов из ответов, часть — общие | каждый значимый образ Мифа прослеживается к ответам кандидатов |
| 2 | **specificity** — конкретность/персональность | подходит любому человеку; общие места | есть 1–2 конкретных якоря | плотная конкретика: детали, сцены, материя, жесты, взятые из ответов |
| 3 | **literary_quality** — зрелость языка | канцелярит, клише, мораль | ровный живой язык, отдельные удачи | текст зрелого автора: точность, ритм, сцены, без псевдоглубины |
| 4 | **non_genericity** — не-универсальность | текст = «сказка про любого» | узнаваемо только с натяжкой | Миф конкретно «про эту четвёрку ответов»; смена ответов сломала бы текст |
| 5 | **insight_delta** — приращение взгляда | пересказ ответов без нового угла | лёгкий сдвиг перспективы | новый, честный угол зрения, который человек мог бы не сформулировать сам |
| 6 | **restraint** — сдержанность | додумывает, домысливает, вторгается | редкие выходы за ответы | не выходит за данные; мягкий открытый финал; никаких обещаний |

(Шкалы 7–9 и задачи D/E — вне рамок Phase-1 и в этом пакете не запрашиваются.)

## 4. Задачи (machine-readable)

### A. Identity Matching (`G1C_PHASE1_IDENTITY_MATCHING.json`)
На каждый Миф — 5 кандидатов-источников (наборы четырёх ответов). Один — истинный. Выберите источник, из которого Миф написан.
- Ответ: `choice` (case_id кандидата), `confidence` (0–10), `evidence` (2–3 цитаты из Мифа ↔ цитаты из ответов).

### B. Counterfactual Swap (`G1C_PHASE1_COUNTERFACTUALS.json`)
Каждому Мифу сопоставлен чужой, но правдоподобный набор ответов. Вопрос: «Обоснован ли этот Миф данным набором?»
- Ответ: `grounded: true|false`, `mismatches: [{myth_quote, answer_ref, reason}]` — минимум 2 цитируемых несовпадения при `false`; при `true` — цитаты, из-за которых Миф «прошёл бы» и по этому набору.

### C. Genericness (`G1C_PHASE1_IDENTITY_MATCHING.json` → `genericness`)
Для каждого Мифа: «Подошёл бы этот текст: только источнику / 2–3 кандидатам / почти всем?»
- Ответ: `label: only_source | few_candidates | most_candidates`, `score` (0–10, где 10 = только источнику), `evidence`.

## 5. Процедура (Phase-1, слепая)

1. Прочитайте этот пакет и `G1C_PHASE1_SCHEMA.json`.
2. Для каждого Мифа из `G1C_PHASE1_MYTHS.jsonl` (с `output.story_result`) выставьте оценки по шкалам 1–6 с цитатами-доказательствами.
3. Выполните задачи A, B, C по соответствующим файлам.
4. Верните один JSON-массив объектов по схеме. `grader_id` — ваш идентификатор (например, ваша модель и версия), `grader_model` — точная модель и версия.
5. Вывод в файл: `G1C_PHASE1_RESULTS_<grader_id>.json` — рядом с этим пакетом.

---

## 6. Анти-предвзятость

- Не штрафуйте литературный текст за отсутствие драмы: часть кейсов намеренно «спокойные».
- Не награждайте драматичность: кейсы с сильными образами — «контрольные», их высокие баллы не делают слабые кейсы хуже.
- Мифы не «подбирались» под кейсы: манифест создан ДО прогона, без подгонки; часть кейсов намеренно сложные/адверсариальные.
- Суд по содержанию, не по длине текста и не по внешнему виду идентификаторов.
