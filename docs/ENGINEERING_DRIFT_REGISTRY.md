### Status Definitions
- `FIXED`: Drift resolved and verified in active code/documentation.
- `LEGACY_MARKED`: Historical document or artifact marked with a prominent archival warning banner so developers and AI agents are not misled.
- `NONBLOCKING`: Documented variance scheduled for surgical remediation during CAMPAIGN-T3 implementation rounds without blocking ongoing operations.
- `OWNER_DECISION`: Action requires owner authorization (e.g. modifying global IDE project registries or pruning old Git worktrees).
- `UNKNOWN`: Unverified or ambiguous variance under ongoing investigation.
