## 2. Валидация входных данных (Strict DOB Validation)

1. Формат даты: строго `DD.MM.YYYY` (8 цифр с точками).
2. Календарная валидность:
   - День $D \in [1, \text{daysInMonth}(M, Y)]$.
   - Месяц $M \in [1, 12]$.
   - Год $Y \in [1900, \text{currentYear}]$.
   - Високосные года проверяются строго по Григорианскому календарю (`29.02.2000` валидно, `29.02.1900` или `31.04.1990` отклоняются с ошибкой).

## 3. Пять ключевых чисел (Пять Зеркал)

Пусть дата рождения задана строкой $DD.MM.YYYY$, где $day$ — числовое значение дня ($1..31$), $month$ — числовое значение месяца ($1..12$), $year$ — год ($1900..2026$).
Определим поразрядную сумму цифр строки $S$ как $\text{sumDigits}(S)$ и пошаговую редукцию числа $N$ до однозначного числа $1..9$ как $\text{reduceVerbously}(N)$, сохраняющую цепочку редукции (композит).

### 3.1. Число Ума / Души (ЧУ / Soul)
- **Композитное число:** Исходный календарный день рождения $day$ (число от 1 до 31).
  $$\text{composite}_{\text{ЧУ}} = day$$
- **Редуцированное число:** Результат редукции дня рождения до $1..9$.
  $$\text{ЧУ} = \text{reduceVerbously}(\text{composite}_{\text{ЧУ}}).\text{value}$$
- **Композитная строка:** Записывается как цепочка редукции, например `6` или `29/11/2`.

### 3.2. Число Выражения / Восприятия (ЧВ / Expression)
- **Композитное число:** Сумма цифр дня рождения плюс сумма цифр месяца рождения:
  $$\text{composite}_{\text{ЧВ}} = \text{sumDigits}(DD) + \text{sumDigits}(MM)$$
- **Редуцированное число:** Результат редукции $\text{composite}_{\text{ЧВ}}$ до $1..9$.
  $$\text{ЧВ} = \text{reduceVerbously}(\text{composite}_{\text{ЧВ}}).\text{value}$$
- **Композитная строка:** Например, для дня `06` и месяца `05`: $6 + 5 = 11 \to \text{"11/2"}$. Для `29.11`: $(2+9) + (1+1) = 11 + 2 = 13 \to \text{"13/4"}$.

### 3.3. Число Действия / Пути / Судьбы (ЧД / Path)
- **Композитное число:** Сумма **всех 8 цифр** полной даты рождения $DD.MM.YYYY$:
  $$\text{composite}_{\text{ЧД}} = \text{sumDigits}(DD) + \text{sumDigits}(MM) + \text{sumDigits}(YYYY)$$
- **Редуцированное число:** Результат редукции $\text{composite}_{\text{ЧД}}$ до $1..9$.
  $$\text{ЧД} = \text{reduceVerbously}(\text{composite}_{\text{ЧД}}).\text{value}$$
- **Композитная строка:** Например, для `06.05.1986`: $6 + 5 + 1 + 9 + 8 + 6 = 35 \to \text{"35/8"}$.

### 3.4. Число Реализации / Направления (ЧР / Direction)
- **Композитное число:** Сумма композитного ЧУ ($\text{composite}_{\text{ЧУ}} = day$) и композитного ЧД ($\text{composite}_{\text{ЧД}}$):
  $$\text{composite}_{\text{ЧР}} = \text{composite}_{\text{ЧУ}} + \text{composite}_{\text{ЧД}} = day + \text{composite}_{\text{ЧД}}$$
- **Редуцированное число:** Результат редукции $\text{composite}_{\text{ЧР}}$ до $1..9$.
  $$\text{ЧР} = \text{reduceVerbously}(\text{composite}_{\text{ЧР}}).\text{value}$$
- **Композитная строка:** Например, для `06.05.1986`: $6 + 35 = 41 \to \text{"41/5"}$.

### 3.5. Число Итога / Результата / Интеграции (ЧИ / Result)
- **Композитное число:** Сумма композитного ЧУ, композитного ЧД и композитного ЧР:
  $$\text{composite}_{\text{ЧИ}} = \text{composite}_{\text{ЧУ}} + \text{composite}_{\text{ЧД}} + \text{composite}_{\text{ЧР}} = day + \text{composite}_{\text{ЧД}} + \text{composite}_{\text{ЧР}}$$
- **Редуцированное число:** Результат редукции $\text{composite}_{\text{ЧИ}}$ до $1..9$.
  $$\text{ЧИ} = \text{reduceVerbously}(\text{composite}_{\text{ЧИ}}).\text{value}$$
- **Композитная строка:** Например, для `06.05.1986`: $6 + 35 + 41 = 82 \to \text{"82/10/1"}$.

## 4. Матрицы и исключение нуля (Zero-Exclusion Invariant)

В ведической нумерологии матрица содержит ровно 9 ячеек, соответствующих 9 планетарным архетипам ($1..9$). Цифра `0` (ноль) **не является планетой** и **категорически исключается** из обеих матриц.

### 4.1. Базовая матрица (`baseMatrix` / Психоматрица)
- Подсчёт частотности каждой цифры $1..9$ исключительно среди цифр исходной даты $DD.MM.YYYY$.
- Ключи объекта: строго `'1', '2', '3', '4', '5', '6', '7', '8', '9'`.
- Цифра `0` строго игнорируется.

### 4.2. Детальная матрица (`detailedMatrix`)
- Базовая матрица **плюс** цифры трёх расчётных композитов:
  1. Цифры $\text{composite}_{\text{ЧД}}$
  2. Цифры $\text{composite}_{\text{ЧР}}$
  3. Цифры $\text{composite}_{\text{ЧИ}}$
- **Важное правило канона:** Цифры ЧВ и промежуточные/конечные одинарные цифры цепочек редукции в детальную матрицу **НЕ входят**. Входят только цифры трех композитов: $\text{composite}_{\text{ЧД}}$, $\text{composite}_{\text{ЧР}}$, $\text{composite}_{\text{ЧИ}}$.
- Цифра `0` строго игнорируется.

## 5. Эталонный расчёт: `06.05.1986` (Reference Golden Case)

1. **Дата:** `06.05.1986`
   - Цифры даты: `0, 6, 0, 5, 1, 9, 8, 6` (ненулевые: `1, 5, 6, 6, 8, 9`)
2. **ЧУ (Число Ума / Душа):**
   - $\text{composite}_{\text{ЧУ}} = 6 \to \mathbf{6}$ (Венера). Композит: `6`.
3. **ЧВ (Число Выражения):**
   - $\text{composite}_{\text{ЧВ}} = (0+6) + (0+5) = 11 \to 1 + 1 = \mathbf{2}$ (Луна). Композит: `11/2`.
4. **ЧД (Число Действия / Судьба):**
   - $\text{composite}_{\text{ЧД}} = 0+6+0+5+1+9+8+6 = 35 \to 3 + 5 = \mathbf{8}$ (Сатурн). Композит: `35/8`.
5. **ЧР (Число Реализации / Направление):**
   - $\text{composite}_{\text{ЧР}} = 6 + 35 = 41 \to 4 + 1 = \mathbf{5}$ (Меркурий). Композит: `41/5`.
6. **ЧИ (Число Итога / Результат):**
   - $\text{composite}_{\text{ЧИ}} = 6 + 35 + 41 = 82 \to 8 + 2 = 10 \to 1 + 0 = \mathbf{1}$ (Солнце). Композит: `82/10/1`.
7. **Базовая матрица (`baseMatrix`):**
   - Цифры из `06.05.1986`: `1: 1`, `2: 0`, `3: 0`, `4: 0`, `5: 1`, `6: 2`, `7: 0`, `8: 1`, `9: 1`.
8. **Детальная матрица (`detailedMatrix`):**
   - Цифры даты (`1, 5, 6, 6, 8, 9`) + цифры композитов:
     - из 35: `3, 5`
     - из 41: `4, 1`
     - из 82: `8, 2`
   - Добавленные цифры: `1, 2, 3, 4, 5, 8`.
   - Итоговая детальная матрица: `1: 2`, `2: 1`, `3: 1`, `4: 1`, `5: 2`, `6: 2`, `7: 0`, `8: 2`, `9: 1`.
