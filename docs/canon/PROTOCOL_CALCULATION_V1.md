## 2. Валидация входных данных (Strict DOB Validation)

1. Формат даты: строго `DD.MM.YYYY` (8 цифр с точками).
2. Календарная валидность:
   - День $D \in [1, \text{daysInMonth}(M, Y)]$.
   - Месяц $M \in [1, 12]$.
   - Год $Y \in [1900, \text{currentYear}]$.
   - Високосные года проверяются строго по Григорианскому календарю (29 февраля допустимо только в високосные года, `29.02.1999` или `31.04.1990` отклоняются).

## 3. Пять ключевых чисел (Пять Зеркал)

Пусть дата рождения представлена компонентами $D$ (день), $M$ (месяц), $Y$ (год).
Определим редукцию суммы цифр числа до одной цифры $1..9$ как $\text{reduce}(N)$:
$$\text{reduce}(N) = 1 + ((N - 1) \pmod 9)$$ для целых положительных чисел.

### 3.1. Число Ума / Души (ЧУ / Soul)
- **Определение:** Сумма цифр дня рождения $D$, редуцированная до $1..9$.
- **Композит:** Записывается как $D / \text{reduce}(D)$ (если $D > 9$) или просто $D$ (если $D \le 9$).

### 3.2. Число Восприятия / Выражения (ЧВ / Expression)
- **Определение:** Сумма дня $D$ и месяца $M$:
  $$S_{DM} = D + M$$
  $$\text{ЧВ} = \text{reduce}(S_{DM})$$
- **Композит:** $S_{DM} / \text{ЧВ}$ (или $S_{DM}/\text{int}/\text{ЧВ}$ при многоступенчатой редукции).

### 3.3. Число Действия / Пути (ЧД / Path)
- **Определение:** Полная сумма даты: сумма дня $D$, месяца $M$ и суммы цифр года $\text{sumDigits}(Y)$:
  $$S_{\text{full}} = D + M + \text{sumDigits}(Y)$$
  $$\text{ЧД} = \text{reduce}(S_{\text{full}})$$
- **Композит:** $S_{\text{full}} / \text{ЧД}$.

### 3.4. Число Реализации / Направления (ЧР / Direction)
- **Определение:** Сумма полной суммы $S_{\text{full}}$ и редуцированного дня $ЧУ$:
  $$S_{\text{dir}} = S_{\text{full}} + \text{ЧУ}$$
  $$\text{ЧР} = \text{reduce}(S_{\text{dir}})$$
- **Композит:** $S_{\text{dir}} / \text{ЧР}$.

### 3.5. Число Итога / Результата (ЧИ / Result)
- **Определение:** Удвоенная сумма направления:
  $$S_{\text{res}} = S_{\text{dir}} \times 2$$
  $$\text{ЧИ} = \text{reduce}(S_{\text{res}})$$
- **Композит:** $S_{\text{res}} / \text{ЧИ}$.

## 4. Матрицы и исключение нуля (Zero-Exclusion Invariant)

В ведической нумерологии матрица содержит ровно 9 ячеек, соответствующих 9 планетарным архетипам ($1..9$). Цифра `0` (ноль) **не является планетой** и **категорически исключается** из матриц.

### 4.1. Базовая матрица (`baseMatrix`)
- Подсчёт частотности каждой цифры $1..9$ исключительно в исходной строке даты $DD.MM.YYYY$.
- Ключи объекта: строго `1, 2, 3, 4, 5, 6, 7, 8, 9`.
- Нули отбрасываются.

### 4.2. Детальная / Расширенная матрица (`detailedMatrix`)
- Подсчёт частотности цифр $1..9$ в исходной дате $DD.MM.YYYY$ **плюс** цифр всех промежуточных расчётных сумм ($S_{DM}, S_{\text{full}}, S_{\text{dir}}, S_{\text{res}}$ и их шагов редукции).
- Ключи объекта: строго `1, 2, 3, 4, 5, 6, 7, 8, 9`.
- Нули отбрасываются.

## 5. Эталонный расчёт: `06.05.1986` (Reference Golden Case)

1. **Дата:** `06.05.1986`
   - $D = 6$, $M = 5$, $Y = 1986$
   - $\text{sumDigits}(Y) = 1 + 9 + 8 + 6 = 24$
2. **ЧУ (Число Ума):**
   - $6 \to \mathbf{6}$ (Венера). Композит: `6`.
3. **ЧВ (Число Выражения):**
   - $D + M = 6 + 5 = 11 \to 1 + 1 = \mathbf{2}$ (Луна). Композит: `11/2`.
4. **ЧД (Число Действия):**
   - $D + M + 24 = 6 + 5 + 24 = 35 \to 3 + 5 = \mathbf{8}$ (Сатурн). Композит: `35/8`.
5. **ЧР (Число Реализации):**
   - $35 + 6 = 41 \to 4 + 1 = \mathbf{5}$ (Меркурий). Композит: `41/5`.
6. **ЧИ (Число Итога):**
   - $41 \times 2 = 82 \to 8 + 2 = 10 \to 1 + 0 = \mathbf{1}$ (Солнце). Композит: `82/10/1`.
7. **Базовая матрица (`baseMatrix`):**
   - Цифры из `06.05.1986` (без 0): `6, 5, 1, 9, 8, 6`
   - `1: 1, 2: 0, 3: 0, 4: 0, 5: 1, 6: 2, 7: 0, 8: 1, 9: 1`
8. **Детальная матрица (`detailedMatrix`):**
   - Цифры даты + `11, 2, 35, 8, 41, 5, 82, 10, 1` (без 0):
   - `1: 5, 2: 3, 3: 1, 4: 1, 5: 2, 6: 2, 7: 0, 8: 3, 9: 1`
